본 문서는 현재 배포된 정적 필터 콘솔(index.html)의 동작을 규정한다. 판정은 규칙 기반(정규화 + 사전 + 정책) 전용이다(AI 분류기 미사용). 산출물은 단일 정적 파일로 GitHub → Vercel 자동 배포된다.

1. 판정 정책

  • 2단계 판정: 통과 / 차단. 마스킹·보류·심각도 단계는 없다.
  • 비속어·음란 표현이 감지되면 차단(후원 불가·재입력 안내, 방송 미노출), 아니면 통과.
  • 검사 대상: 방송에 노출·낭독되는 입력(이름·텍스트 내용). 재입력 안내 시 구체 금칙어는 노출하지 않는다(우회 학습 방지).
  • 우선순위: 화이트리스트 > 블랙리스트. 화이트리스트/맥락 예외에 해당하는 부분은 판정 전에 제거된다.

2. 정규화 파이프라인 구현

입력을 표준형(자모 시퀀스)으로 수렴시켜 변형을 한 형태로 통일한다. 순서 고정, 규칙 기반.

  1. 유니코드 정규화(NFKC) → 소문자화
  2. 유사문자·숫자 치환(1→ㅣ, 0→ㅇ 등) — 예: 시1발
  3. 구분자·공백·특수문자 제거 — 예: 시★발, 시 발
  4. 영타 역변환(두벌식 자판) — 예: tlqkf → 시발
  5. 한글 자모 분해(NFKD → 호환 자모) — 예: 시발 → ㅅㅣㅂㅏㄹ
  6. 연속 동일 자모 축약(ㅋㅋㅋ→ㅋ) → 허용 문자(한글 자모·영숫자)만 유지

보조 키: 독립 초성(ㅅㅂ), 음역 표준형(ssibal).

CANON_MIN은 부분매칭 최소 자모 수다. 낮출수록 짧은 단어를 잡지만 정상어 오탐이 늘어 자동 화이트리스트가 커진다. 값 변경 시 scripts/gen_whitelist.mjs의 동일 상수도 맞추고 재생성한다.

4. 사전 구성 구현

  • 블랙리스트(차단): 공개 목록 lisuugi(레벨 1~2 전 카테고리) + hlog2e를 구분 없이 병합해 기본 탑재(약 3,670개). 관리자 추가/삭제 가능.
  • 수동 화이트리스트(통과): 관리자가 직접 관리하는 예외(예: 시발점).
  • 자동 화이트리스트: 국어사전 명사 중 “블랙리스트 canon(≥CANON_MIN)을 부분문자열로 포함하되 그 자체는 슬러가 아닌” 정상어(현재 약 2,100개). 검색·단어별 삭제 제공(삭제 시 예외 해제 → 다시 차단 대상, 재생성해도 삭제 유지).
  • 저장/매칭: 등록 단어는 표준형으로 대조. 화이트리스트는 원문에서 먼저 제거 후 판정.

5. 오탐(false positive) 처리 — 3계층

계층대상동작
① 자동 화이트리스트(명사)깨끗한 정상 복합어시발점·자위권·눈자위 등 원문에서 제거 → 통과
② 맥락 예외 CONTEXT_SAFE동음이의 동사 활용보지 마세요·자지 마·자지러지다·보지 못했어요 통과 / 보지·자지 단독 차단
③ 우회 차단특수문자·자모분리·숫자삽입시★발·ㅅㅂ 정규화+부분/초성 매칭으로 차단(화이트리스트가 새지 않음)

맥락 예외 규칙 (② 계층 상세)

⚠ 이 예외는 아래 표의 딱 2개 단어(보지, 자지)에만 적용되는 특별 케이스다. 다른 모든 블랙리스트 단어(시발·자위·개새끼 등 수천 개)에는 적용되지 않으며, 그 단어들은 예외 없이 일반 규칙(정규화 + 부분매칭)으로 그대로 차단된다.

배경: 한국어 어미 -지는 거의 항상 마/말/못/않(부정 보조용언)과 결합한다. 그래서 보지(보다+지)·자지(자다+지)는 글자만 같고 뜻은 동사인 경우가 흔하다. 이 두 단어에 한해, 뒤에 지정된 접미가 붙으면 동사로 간주해 그 부분만 판정 전에 제거한다.

적용 단어뒤에 이 글자가 오면 통과(허용 접미)통과 예시(동사)차단 예시(단독/슬러)
보지마 / 말 / 못 / 않보지 마세요, 보지 못했어요, 해보지 마보지, 보지 만져, 보지 사진
자지마 / 말 / 못 / 않 / 러자지 마(잠), 자지 못했다, 자지러지다자지, 자지 크기

중요: 이 두 단어는 뒤에 위 접미가 붙으면 통과한다. 예) 자지만 블랙리스트에 넣어도 자지마는 통과(자지+마), 자지 단독은 차단. 이는 자지 마(잠)·자지러지다 같은 정상 문장을 막지 않기 위한 의도된 동작이다.

이 목록은 코드의 CONTEXT_SAFE 맵에 하드코딩된 수작업 규칙이다. 단어를 추가·삭제하려면 CONTEXT_SAFE를 직접 수정한다(예: 자지를 빼면 자지 마·자지러지다까지 모두 차단됨).

6. 사전 관리 기능 구현

  • 입력창 = 검색 겸용: 타이핑하면 실시간 검색, Enter/추가 버튼으로 추가. 입력값이 있으면 X(지우기) 버튼 노출.
  • 단어별 삭제(×), 중복 추가 방지. 블랙리스트·수동/자동 화이트리스트 모두 칩별 삭제 지원.
  • 자동 화이트리스트 삭제: 칩의 ×로 개별 제거. 제거된 단어는 예외 해제 → 다시 차단 대상이 되며, 삭제 집합(WL_AUTO_REMOVED)에 보관되어 재생성해도 되살아나지 않는다(블랙리스트 삭제와 동일 방식). 세션(브라우저 메모리) 기준.
  • 엑셀 다운로드: 현재 목록 → .xlsx. 엑셀 업로드: 첫 열 단어를 현재 목록에 일괄 추가(중복 제외). SheetJS 사용, 미로드 시 CSV 폴백.
  • 자동 화이트리스트 재생성: 운영자가 블랙리스트를 수정하면 “현재 블랙리스트로 재생성” 버튼으로 브라우저에서 즉시 재계산. 개수가 생성 시점과 다르면 “재생성 권장” 경고 표시. 영구 반영은 node scripts/gen_whitelist.mjs 후 whitelist_auto.json 커밋.

9. 한계 & 향후

  • 한계 동음이의 문맥(존나 좋다 강조 vs 욕설)이나 시이이발류 음절 삽입 변형은 규칙 기반의 구조적 한계로 정확 판별이 어렵다. 신규 우회 패턴은 블랙리스트·정규화 규칙·맥락 예외(CONTEXT_SAFE)를 수기로 보강하고 운영자 검수로 대응한다.
  • 동음이의 단독어(시발=始發)는 후원 맥락상 계속 차단이 타당.
  • 예정 후원 페이지 연동(결제·노출 이전 필터 호출), 프로덕션 백엔드(DB·API, 사전 캐시·변경 즉시 반영·차단 로그), 회원 신고제재(별도 기획).

부록 A. 자동 화이트리스트 로직 (상세)

A-1. 왜 필요한가 (문제)

필터는 블랙리스트 단어를 부분문자열(substring)로 매칭한다. 이러면 비속어가 정상 단어의 일부일 때도 걸린다.

  • 시발(욕) 등록 → 시발점(始發點, 출발점)까지 차단
  • 자위 등록 → 자위권·자위대(自衛, 자기방어)·눈자위까지 차단

이런 충돌 단어를 사람이 손으로 화이트리스트에 넣는 것은 범위가 너무 넓어 불가능하다. 그래서 국어사전에서 자동으로 뽑는다.

A-2. 핵심 아이디어 (한 문장)

국어사전 명사 중에서 “블랙리스트 표준형을 부분문자열로 포함하지만 그 자체는 슬러가 아닌” 단어만 골라 예외(통과) 목록으로 만든다.

A-3. 용어

  • 표준형(canon): normalize()를 거친 자모 시퀀스. 예) 시발 → ㅅㅣㅂㅏㄹ, 시발점 → ㅅㅣㅂㅏㄹㅈㅓㅁ.
  • CANON_MIN: 부분매칭 대상이 되는 표준형 최소 자모 수(현재 4). 블랙리스트 단어라도 표준형이 이보다 짧으면 부분매칭 대상이 아니다.
  • canon 집합: 블랙리스트 각 단어의 표준형 중 길이 ≥ CANON_MIN 인 것들의 집합(= 런타임 BLCANON의 키).

A-4. 생성 알고리즘 (의사코드)

canonSet = { normalize(w) | w ∈ 블랙리스트, |normalize(w)| ≥ CANON_MIN }

for 명사 W in 국어사전(표준국어대사전 명사 ~19만):
    if W ∈ 블랙리스트:            continue   # 슬러 자체는 제외
    c = normalize(W)
    if |c| < CANON_MIN:            continue   # 너무 짧으면 부분매칭 대상 아님 → 오탐 없음
    if c ∈ canonSet:              continue   # ★ 표준형이 슬러와 '정확히' 같으면 제외(계속 차단)
    if c 가 canonSet의 어떤 원소를 부분문자열로 포함:
        자동_화이트리스트 += W                # 오탐 유발 정상어 → 예외로 등록

마지막 조건(부분문자열 포함 검사)은 canon이 수천 개라 Aho-Corasick 오토마톤으로 한 번의 스캔에 처리한다(명사 19만 × canon 수천 을 순진하게 곱하면 수억 회 → 실사용 불가).

A-5. 두 제외 조건이 중요한 이유

  • W ∈ 블랙리스트 → 제외: 사전에는 씨발·개새끼 같은 욕도 표제어로 실려 있다. “사전에 있으니 통과”는 위험 → 슬러 자체는 화이트리스트에 넣지 않는다.
  • c ∈ canonSet(정확 일치) → 제외: 표준형이 슬러와 똑같은 단어는 계속 차단. 예) 시발(始發)은 표준형이 ㅅㅣㅂㅏㄹ로 슬러와 동일 → 제외되어 계속 차단. 반면 시발점은 더 길어 정확 일치가 아니므로 통과 목록에 포함. (동음이의 단독어는 후원 맥락상 차단 유지)

A-6. 워크드 예제

시발점ㅅㅣㅂㅏㄹㅈㅓㅁ추가ㅅㅣㅂㅏㄹ 포함, 자기 자신은 슬러 아님

안녕 / 방송ㅇㅏㄴㄴㅕㅇ / …제외어떤 canon도 포함하지 않음(애초에 오탐 없음)

A-7. 런타임에서 어떻게 쓰이나

  • 판정 직전 stripWhitelist()가 원문에서 (수동+자동) 화이트리스트 단어를 제거한다. 예) "시발점에서 만나요" → 시발점 제거 → 남은 텍스트에 슬러 표준형 없음 → 통과.
  • 여러 단어가 겹칠 때를 위해 긴 단어부터 제거한다(최장일치). 성능을 위해 includes 가드 후 치환.
  • 중요: 화이트리스트는 원문(깨끗한 텍스트)에서 제거하므로, 우회 표기(시★발)에는 적용되지 않는다 → 우회는 그대로 차단(2계층 분리).
  • 병합 캐시 WL_ALL = 수동 WHITELIST + 자동 WL_AUTO − 삭제분 WL_AUTO_REMOVED. 운영자가 자동 화이트리스트에서 ×로 삭제한 단어는 WL_AUTO_REMOVED에 들어가 병합에서 제외되고, 재생성(로드/재계산) 후에도 계속 제외된다 → 해당 단어는 다시 차단 대상.

A-8. 데이터 흐름 & 파일

  • 오프라인 배치 scripts/gen_whitelist.mjs — 블랙리스트(lisuugi+hlog2e)와 명사사전을 받아 위 알고리즘으로 whitelist_auto.json 생성. 정규화는 index.html의 normalize()를 그대로 추출해 사용(런타임과 100% 동일).
  • 브라우저 — 페이지 로드시 자사 whitelist_auto.json을 불러와 화이트리스트에 병합.
  • 즉시 재생성 — 운영자가 블랙리스트를 수정하면 “현재 블랙리스트로 재생성” 버튼이 명사사전을 받아 현재 블랙리스트 기준으로 브라우저에서 재계산(오프라인 배치와 동일 결과). 영구 반영은 배치 재실행 후 whitelist_auto.json 커밋.

A-10. 한계 (중요)

자동 화이트리스트는 국어사전 ‘명사’만 예외 처리한다. 따라서 보지 마세요(보다+지), 자지러지다 같은 동사 활용형은 명사가 아니라서 이 목록으로 못 살린다 → 이것은 맥락 예외(CONTEXT_SAFE, 5장)가 담당한다. 규칙으로 못 가르는 신종 문맥은 본 시스템 범위 밖(구조적 한계)이며, 블랙리스트·맥락 예외 수기 보강으로 대응한다.

부록 B. 판정 처리 흐름 & 검증 예제

B-1. 처리 순서 (파이프라인)

한 건의 입력은 dictDetect()에서 아래 순서로 처리된다. 앞 단계에서 제거된 부분은 뒤 단계에서 검사되지 않는다(그래서 정상어·동사형은 제거되어 통과, 우회는 남아서 차단).

입력 원문
 │
 ├ ① stripWhitelist    (수동+자동) 화이트리스트 단어 제거   ← 자동 화이트리스트(명사)
 ├ ② stripContextSafe  동음이의 동사형 제거 ← 맥락 예외(보지·자지 2개 단어에만)
 ├ ③ normalize         표준형(자모 시퀀스)으로 변환  ← 우회 복원(특수문자·영타·자모분해)
 │
 └ 매칭  ④ 표준형 부분매칭 (canon 길이 ≥ CANON_MIN)
         ⑤ 초성 매칭 (ㅅㅂ 등)      ⑥ 음역 매칭 (ssibal 등)

   → ④⑤⑥ 중 하나라도 걸리면 '차단', 아니면 '통과'

B-2. 검증 예제 (회귀 테스트)

아래는 코드 변경 시 유지되어야 하는 기준 판정이며, 각 행이 어느 단계에서 결정되는지를 함께 표기한다. 실제 판정 함수(evaluate())로 검증했다(15/15 통과). 오프라인 배치와 브라우저 재생성이 동일 결과임도 확인.

입력결과결정 단계설명
보지 / 자지 / 자위차단④ 표준형 부분매칭4자모 표준형이 블랙리스트 canon과 일치(CANON_MIN=4)
보지 마세요 / 보지 못했어요 / 해보지 마통과② 맥락 예외보다+지 → 마/못 → 동사로 판단해 ‘보지’ 부분 제거
자지 마(자다) / 자지러지게 웃었다통과② 맥락 예외자다+지 → 마 / 자지러 → 러 → 해당 부분 제거
보지 만져 (슬러)차단④ 표준형 부분매칭‘만’은 허용접미(마/말/못/않)가 아님 → 맥락 예외 미적용 → 그대로 매칭
자위권 발동 / 눈자위가 떨려통과① 자동 화이트리스트국어사전 명사(자위권·눈자위)로 등록되어 원문에서 제거
시★발 (우회)차단③→④정규화가 ★ 제거 → ‘시발’ 표준형 복원 → 매칭(화이트리스트는 우회에 미적용)
ㅅㅂ (초성)차단⑤ 초성 매칭독립 초성 우회 탐지

※ 이 표는 개발 시 회귀 검증 체크리스트로 사용한다. 정규화·임계값(CANON_MIN)·맥락 예외(CONTEXT_SAFE)·자동 화이트리스트를 수정하면 이 결과가 유지되는지 다시 확인한다.
